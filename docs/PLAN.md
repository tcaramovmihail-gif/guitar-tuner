# План проекта: гитарный тюнер + песни с аккордами

Статус: MVP собран и проверяется на реальном телефоне. Документ — источник истины
по объёму и порядку работ. Обновлять при изменении решений.

## 1. Продукт

Android-приложение для гитариста:

1. **Тюнер** — определяет ноту и отклонение в центах по микрофону, поддерживает
   стандартный строй, Drop D, на полтона ниже, укулеле, бас и хроматический режим.
   На экране нарисована гитара: подсвечивается струна, которую сейчас настраивают.
   Есть стабильный/быстрый захват и эталонный тон выбранной струны для настройки на слух.
2. **Библиотека песен** — локальные песни с аккордами, папки по исполнителям, поиск,
   открытие и сохранение песен с AmDm, транспонирование, подсказка про капо.
3. **Просмотр песни** — текст с аккордами, автопрокрутка в темпе BPM и слышимый
   метроном: деревянный щелчок или барабанная партия (бочка/малый/тарелка).

Офлайн-first: библиотека и тюнер работают без сети. Интернет нужен только для поиска
и загрузки песен. Без аккаунта. Русский интерфейс. Публикация — RuStore (APK/AAB).

### Границы MVP

- Тюнер: монофонический, одна нота за раз, диапазон E1–E6 (41–1319 Гц), точность ±1 цент
  на синтетике и ±3 цента на живой струне, задержка отклика ≤ 100 мс.
- Песни: локальная SQLite-база, папки по исполнителям, демо-набор, импорт с AmDm,
  дедупликация по исполнителю и названию, транспонирование в пределах −6…+6 полутонов.
- Автопрокрутка: постоянная скорость от BPM, пауза/продолжение, ручная коррекция.
- Метроном: 4/4, акцент на первой доле, тот же BPM, что и у автопрокрутки; режим
  барабана с простым backbeat.
- Эталонный тон: синтезированная нота открытой струны, без аудиофайлов.
- Без аудиоплеера, облака и синхронизации с записью в MVP.

## 2. Ключевые технические решения

| Решение | Выбор | Почему |
| --- | --- | --- |
| Язык/UI | Kotlin + Jetpack Compose | нативный аудиовход, один APK, предсказуемый RuStore |
| Мин. версия | minSdk 26 (Android 8.0) | покрытие устройств, современные API аудио |
| Целевая | targetSdk 36 (Android 16) | требования магазинов 2026 |
| Сборка | Gradle 8.13 + AGP 8.13.2 | стабильная связка; обновление до AGP 9 — отдельной задачей |
| Kotlin | 2.4.21, JDK 17 | совместимость с AGP и Compose |
| UI | Compose BOM 2025.09.01, Material 3 | совместимо с AGP 8.13; обновление вместе с AGP 9 |
| Звук | `AudioRecord` + PCM float, 48 кГц, окно 4096 | без лишних зависимостей; позже Oboe/NDK при необходимости |
| DSP | YIN + медианный фильтр + EMA | устойчив к обертонам, дёшев на CPU |
| Хранение | `SQLiteOpenHelper` (`songs.db`) | простая схема без внешних ключей; не тянет KSP в Kotlin 2.4.21; Room — при росте схемы и миграциях |
| Каталог | Jsoup 1.23.2 + `HttpURLConnection` в `:core:catalog` | HTML AmDm разбирается одним парсером, без тяжёлого HTTP-клиента |
| Метроном | синтез стука в памяти + `AudioTrack` | без аудиофайлов и лицензий, задержка предсказуема |
| DI | вручную (позже Hilt при росте) | меньше магии на старте |
| Навигация | Compose Navigation (позже), сейчас состояние | каркас проще |

### Тюнер: обработка сигнала

```text
AudioRecord (48 кГц, mono, float, UNPROCESSED→MIC)
  → окно 4096 (85 мс), шаг 1024–2048
  → YIN: difference → CMND → порог 0.15 → параболическая интерполяция
  → частота + clarity + rms
  → фильтр: медиана 7 кадров, EMA 0.18, гейт по clarity/rms
  → нота, октава, центы, стрелка
```

- Низкая E2 (82.4 Гц) требует окна не меньше 4096 при 48 кГц — иначе октавные ошибки.
- `UNPROCESSED` предпочтителен: шумоподавление телефона режет низ гитары. Если источник
  не поддерживается — fallback на `MIC`.
- Разрешение `RECORD_AUDIO` запрашивается только на экране тюнера, с объяснением.
- Сглаживание обязательно: без него стрелка дрожит на 5–10 центов.
- Проверка октав: кандидат сравнивается с предыдущей нотой и суммой гармоник; при
  уверенном промахе на октаву — коррекция.
- Струна определяется по классу высоты (`MIDI % 12`) и ближайшей открытой струне;
  частота и центы сворачиваются в октаву этой струны, поэтому гармоника не сбивает экран.
- После захвата цель фиксируется (`StringTargeting`): пока нота звучит, струна не меняется,
  даже если пришёл обертон (A3 при настройке G3) или струна уехала по высоте. Смена —
  только при точном попадании в другую открытую струну (±100 ¢); после паузы — заново.
- Гармоники активной струны не переключают цель: 3-я гармоника A2 = открытая E4,
  3-я E2 = B3, 4-я E2 = E4. `PitchMath.harmonicOf` узнаёт целое кратное (±150 ¢:
  гармоника уезжает вместе с расстройкой струны), `foldToTarget` делит на него
  частоту — обертон показывает те же центы, а цель стоит.
- Активную струну удерживает `StringTracker`. Профиль «Стабильный» (по умолчанию):
  первый захват — 6 кадров, смена — 16 кадров, после тишины подсветка держится 22.
  Профиль «Быстрый»: 3 / 6 / 8. Одиночные выбросы и короткие обертоны не переключают струну.
- Порог захвата струны: «Стабильный» — `clarity ≥ 0.86`, RMS ≥ 0.010 после усиления;
  «Быстрый» — `0.78` / `0.006`. Струна выбирается по сглаженной частоте, поэтому
  сырой выброс не меняет подсветку. Экран обновляется только по уверенным кадрам,
  последняя нота держится 12 кадров (≈1 с), частота догоняет новую с коэффициентом 0.55.
- «Коза» при успехе: `InTuneHold` копит время в строю — 30 кадров (≈2.5 с звучания,
  допуск ±8 ¢), после чего человечек поднимает руку. Тишина и затухание прогресс
  не сбрасывают, поэтому повторные щипки складываются; сбрасывает устойчивый промах
  (3 кадра подряд хуже ±9 ¢), смена струны, строя, A4, стоп и профиль захвата.
- Индикатор «Сигнал» начинается от порога захвата, а не от нуля АЦП: в тишине он
  показывает 0 %, хотя микрофон усилен в 8 раз.
- Ручной режим: тап по струне или колку на рисунке гитариста либо по чипу 6…1
  фиксирует выбранную струну. Кнопка «Авто» возвращает автоопределение; в ручном
  режиме видно, если играет другая струна, и шкала не показывает ложные центы.
- Эталонный тон: кнопка «Тон» у активной струны выключает микрофон и играет
  синтезированную ноту через `ReferenceTone`; это режим настройки на слух.
- На экране — стилизованный гитарист с соразмерной гитарой: активная струна
  подсвечивается, кисть тянется к колку, рядом показано «Струна 6 (E2) · Подтянуть».
  На гитаристе тёмная куртка поверх белой футболки с принтом «rock». После ≈2.5 с
  в строю свободная рука поднимается с «козой» (кулак, указательный и
  мизинец вверх, средний и безымянный зажаты, большой палец отставлен).
  Чипы струн показывают номер и ноту, статус вынесен в цветную пилюлю, A4 открывается
  из меню строя, есть переключатель захвата. Номер струны считается от низкой к высокой.
- Иконка приложения: адаптивная гитара на тёмно-зелёном фоне, отдельные base- и
  round-ресурсы для лаунчеров.

### Метроном

- 4/4, BPM общий с автопрокруткой, акцент на первой доле.
- Звук — синтезированный короткий стук: низкий тон с шумовым призвуком и быстрым
  затуханием, без высокого «писка». Слышен на динамике телефона и не перекрывает гитару.
- Режим «Барабан» — синтезированный backbeat: бочка на 1 и 3, малый на 2 и 4,
  тарелка на каждой доле. Смена звука применяется со следующей доли.
- `AudioTrack` в режиме потока, `USAGE_MEDIA` / `CONTENT_TYPE_SONIFICATION`, без разрешений.
- Запуск и остановка привязаны к экрану песни; при уходе с экрана метроном глушится.

### Автопрокрутка: сравнение вариантов

| Вариант | Как | Плюсы | Минусы |
| --- | --- | --- | --- |
| A. Постоянная скорость от BPM (MVP) | `px/s = BPM/60 × высота_доли` | нет разметки, работает для любой песни, предсказуемо | нет привязки к конкретным строкам, темп надо знать |
| B. Сетка долей и якоря секций | у секции/строки число долей, интерполяция между якорями | точная синхронизация, поддержка пауз/вставок | нужен редактор разметки, сложнее импорт |
| C. Синхронизация с аудио | минусовка + beat grid | идеально для выступления | лицензии на музыку, вес APK, сложно |

**Решение:** A сейчас, B — следующим этапом (директивы ChordPro `{tempo: 96}`,
`{scroll: 1.0}`, якоря секций), C — только по запросу.

Реализация A:

- скорость в px/с считается от BPM и density: `bpm / 60 * 22.dp.toPx()`;
- движение — покадрово через `withFrameNanos` и `ScrollState.dispatchRawDelta`, без
  анимации каждого элемента списка: не дёргается и не нагружает компоновку;
- пауза/продолжение, «в начало», слайдер BPM 40–220, позже tap-tempo и множитель 0.5–2×;
- ручной скролл пользователем ставит автопрокрутку на паузу, чтобы не бороться с пальцем;
- экран не гаснет (`KEEP_SCREEN_ON`), громкость/педаль — позже;
- на длинных песнях используем `Column + verticalScroll`, а не `LazyColumn`: весь текст
  в памяти, зато позиция и скорость абсолютно стабильны.

## 3. Этапы

### Этап 0. Среда и каркас (готово)

- SDK, эмулятор, JDK, Gradle, ADB, скрипты, AGENTS.md, агенты, MCP-политика.
- Каркас многомодульного проекта, сборка debug APK, unit-тесты DSP.
- **Готово:** `gradlew :core:dsp:test :app:assembleDebug` зелёный; APK ставится
  на реальный телефон. Эмулятор на этой машине недоступен (нет EPT/URG), UI проверяем
  на устройстве.

### Этап 1. Тюнер (готово)

- Экран: большая нота, центы, шкала, индикатор сигнала, выбор строя, A4.
- Гитарный гриф: подсветка текущей струны и подпись с номером и нотой.
- `TunerViewModel`: разрешение, запуск/остановка захвата, поток результатов, ошибки.
- Сглаживание и октавная коррекция, гейт тишины.
- `StringTracker`: удержание активной струны, пороги захвата/смены, ручной выбор
  с грифа и чипов, возврат в «Авто». JVM-тесты на захват, смену, паузу и выбросы.
- Иконка приложения: adaptive icon, base/round mipmap, проверка в информации о приложении.
- Тесты: синтетика по всем струнам ±50 центов, шум/тишина.
- **Готово, когда:** на реальном телефоне все 6 струн определяются за ≤0.5 с,
  ошибка ≤3 центов, ложных нот в тишине нет, а подсветка не скачет на одиночных
  выбросах. Ручной выбор не сбрасывается до нажатия «Авто». Финальный прогон — в этапе 4.
- **Доработка (собрано, ждёт проверки на телефоне):** фиксация цели, гармоники
  активной струны, сглаживание и удержание ноты, «коза» после ≈2.5 с в строю
  (`InTuneHold`, JVM-тесты), соразмерная гитара.

### Этап 2. Песни и хранилище (готово)

- SQLite: таблица `songs` (id, title, artist, bpm, chords, song_key, source_url, saved_at).
- Папки по исполнителям, поиск, демо-данные, сохранение и замена импортированных песен.
- Каталог AmDm: список популярных, поиск, разбор страницы, выбор версии с галочкой.
- Импорт «Король и Шут» и «Би-2»: 283 и 204 уникальные песни соответственно.
- Транспонирование на −6…+6 полутонов, определение тональности, подсказка про капо.
- **Готово, когда:** песня открывается, транспонируется и переживает перезапуск;
  повторный импорт не создаёт дублей.

### Этап 3. Автопрокрутка и метроном (готово)

- Движок скорости, пауза/продолжение, BPM, сброс, keep-screen-on.
- Метроном со стуком, синхронный с BPM, акцент на первой доле.
- Поведение при ручном скролле, сворачивании, смене ориентации.
- Юнит-тесты чистой математики скорости; UI-тест пауза/продолжение.
- **Готово, когда:** 3-минутная песня проезжает без рывков, позиция сохраняется при
  повороте, метроном слышен и не отстаёт от BPM.

### Этап 4. Полировка и качество (текущий)

- Тёмная/светлая тема, доступность (крупные цели, контраст), локализация RuStore.
- Иконка и adaptive icon проверены на лаунчере/экране приложения.
- Линт, R8, baseline profiles (по необходимости), размер APK.
- Прогон на 2–3 реальных устройствах, батарея/нагрев 10 минут тюнера.
- Сделано в текущей итерации: стабильный/быстрый захват струны, эталонный тон,
  режим барабана, статус-пилюля, ноты на чипах, A4 в меню, переключатель захвата.
  Эти изменения собраны и покрыты JVM-тестами; осталась проверка на телефоне.

### Этап 5. RuStore

- Уникальный `applicationId` (сейчас `ru.eurovafel.guitartuner`, подтвердить).
- Upload keystore вне git, `keystore.properties` локально/в секретах.
- Подписанный AAB/APK, versionCode, иконка 512×512, ≥3 скриншота, описание,
  политика конфиденциальности (микрофон), декларация разрешений.
- **Готово, когда:** версия принята модерацией, установка из RuStore работает.

### Этап 6 (опционально). Продвинутая синхронизация

- Якоря секций, tap-tempo, педаль по громкости, синхронизация с минусовкой.

## 4. Качество: ворота

1. `./gradlew :core:dsp:test :core:model:test :core:catalog:test :core:audio:test` —
   все JVM-тесты зелёные.
2. `./gradlew :app:assembleDebug` — сборка без ошибок.
3. `./gradlew :app:lintDebug` — нет ошибок уровня error.
4. Реальный телефон: тюнер проверен на всех струнах, гитара подсвечивает нужную,
   песня открывается, транспонируется, автопрокрутка и метроном работают.
5. Каталог: поиск, открытие и сохранение песни; повторный импорт не плодит дубли.
6. Секреты и ключи не в git; `local.properties`, `*.jks`, `keystore.properties` игнорируются.

## 5. Риски

| Риск | Проявление | Мера |
| --- | --- | --- |
| Микрофон эмулятора | нет/искажённый вход | точность проверяем на телефоне и синтетике, эмулятор — только UI |
| Низкие частоты | октавные ошибки на E2 | окно 4096, YIN, проверка гармоник |
| Шумоподавление ОС | «плавает» нота | `UNPROCESSED`, гейт, сглаживание |
| Разные микрофоны | разная чувствительность | калибровка усиления, порог RMS |
| Автопрокрутка «уезжает» | темп не совпадает | множитель скорости, tap-tempo, якоря (этап 6) |
| Разметка AmDm меняется | парсер перестаёт находить аккорды | тесты на сохранённых страницах, понятная ошибка без потери библиотеки |
| Много запросов к AmDm | блокировка по IP | 4 параллельных запроса, пауза 100 мс, импорт батчами |
| SQLite без миграций | потеря данных при смене схемы | версия БД и явная миграция до изменения структуры |
| RuStore-подпись | отказ/невозможность обновления | ключ создаётся один раз, бэкап вне git |
| AGP 8 → 9 | устаревание | отдельная задача миграции, проект на 8.13 стабилен |
