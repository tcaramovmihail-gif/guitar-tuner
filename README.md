# Гитарный тюнер

Android-приложение для гитариста: тюнер по микрофону, библиотека песен с аккордами,
автопрокруткой, транспонированием, барабанным метрономом, карта мест игры и обратная
связь. Интерфейс на русском, аккаунт не нужен, основные функции работают офлайн.

## Скачать и установить

**[Скачать APK 0.7.0](https://github.com/tcaramovmihail-gif/guitar-tuner/releases/latest/download/guitar-tuner-0.7.0.apk)**

- Android 8.0+ (minSdk 26).
- При установке разрешите установку из неизвестных источников.
- При первом запуске тюнера выдайте доступ к микрофону, для карты — к геолокации.
- Это тестовая сборка: APK подписан тестовым ключом Android Debug и не предназначен
  для публикации в RuStore. Для магазина понадобится отдельный release-ключ.

Все версии и заметки к релизам: [Releases](https://github.com/tcaramovmihail-gif/guitar-tuner/releases).

## Что умеет

### Тюнер

- Автоопределение активной струны по звуку микрофона.
- Цель фиксируется после определения струны: пока нота звучит, эталонная частота
  не меняется, поэтому ползунок не скачет на обертонах и затухании. Гармоники
  активной струны (3-я у A2 совпадает с E4, 3-я у E2 — с B3) не считаются другой
  струной и показывают те же центы.
- Два профиля захвата: «Стабильный» (по умолчанию) и «Быстрый». Стабильный дольше
  держит струну и не перескакивает на обертонах и случайном шуме.
- Удержание струны и ноты: подсветка не прыгает на одиночных выбросах, экран
  обновляется только по уверенным кадрам, последняя нота держится около секунды.
- «Коза» при успехе: если струна продержалась в строю около 2.5 секунд (допуск ±8 ¢,
  выход — ±9 ¢), гитарист поднимает руку.
- Ручной выбор струны тапом по гитаристу (струна или колок) или чипами 6…1,
  возврат в режим «Авто».
- Последовательная настройка 6 → 1: у настроенных струн появляется галочка,
  после попадания в ноту тюнер сам переходит к следующей. Когда настроены все
  шесть, показывается баннер «Все струны настроены».
- Короткий вибро-отклик, когда струна попала в ноту (можно выключить).
- Эталонный тон выбранной струны: кнопка «Тон» выключает микрофон и играет ноту
  для настройки на слух.
- Стандартный гитарный строй, а также другие строи из `InstrumentTuning`.
- Калибровка A4 в диапазоне 430–450 Гц (в меню строя).
- Показ ноты, отклонения в центах, уровня сигнала и уверенности детектора. Индикатор
  сигнала начинается от порога захвата, поэтому в тишине показывает 0 %.
- Иллюстрация: гитарист в тёмной куртке поверх белой футболки с принтом «rock».
  Рядом сидит пёс. По нажатию он говорит две строчки — «А не спеть ли мне песню....»
  и «ооооо любви» — с паузой в две секунды.
- Отдельный экран настроек: четыре цветовые схемы (мятная, золотая, синяя,
  фиолетовая), светлая/тёмная/системная тема, масштаб текста, пауза перед стартом,
  скорость прокрутки, вибро и последовательная настройка. Всё сохраняется между
  запусками.
- Отдельный полноэкранный метроном с крупным визуальным пульсом и размером такта
  2/4, 3/4, 4/4 или 6/4.

### Песни

- Локальная библиотека песен с аккордами, папки по исполнителям и поиск.
- Импорт песен с AmDm, Akkords.pro, 501 AmDm и 5Lad.
- Поиск идёт только по выбранному источнику — чипы «AmDm», «Akkords.pro»,
  «AmDm 501», «5Lad». Смена источника очищает прошлые результаты.
- Сортировка по алфавиту, исполнителю, недавним и часто играемым; фильтры «Все»,
  «Свои» и «Из каталога». Выбор сохраняется.
- Своя песня вручную: название, исполнитель, темп и текст с аккордами. Любую
  сохранённую песню можно отредактировать из карточки или меню песни.
- Транспонирование аккордов и автопрокрутка текста в темпе песни.
- Темп сохраняется прямо в песню. Пауза перед стартом (0/3/5/10 секунд) считается
  по настройке, есть tap-tempo и множитель скорости прокрутки. Позиция текста
  запоминается отдельно для каждой песни.
- Компактный рабочий экран: максимум текста, масштаб и темп — двумя строками,
  «Звук и рисунок», скорость и редактирование убраны в верхние меню. Масштаб
  по умолчанию 75 %, последний выбор запоминается для всех песен. После «Играть»
  текст стоит выбранную паузу и только потом начинает идти вниз.
- Касание аккорда в тексте показывает аппликатуру; для незнакомых аккордов
  строятся простые баррэ-формы, а сложные созвучия честно не показываются.
- В карточке и в песне видно источник и версию приложения. Каталог кэшируется
  на устройстве: при отсутствии сети показываются сохранённые результаты.
- Избранное: сердечко в карточке песни и отдельная папка.
- Выбор песен чекбоксами и групповое удаление с подтверждением.
- Барабанный метроном: пять рисунков, темп песни, восьмые; бочка, малый барабан
  и тарелка звучат синтезом, без внешних сэмплов. Отдельный экран метронома
  открывается из шапки тюнера, настроек и меню песни.
- Все кнопки и панели используют собственные векторные иконки вместо текстовых
  символов.
- Вкладка «Аккорды»: базовые аккорды с аппликатурами и прослушиванием.

### Карта мест игры

- При нажатии «Играть» приложение отмечает место по геолокации и ставит на карту
  маленькую гитару.
- Все песни, сыгранные в радиусе 300 метров, объединяются в одну гитару.
- Касание гитары открывает историю: какие песни здесь играли и когда.
- Повтор той же песни в течение 15 минут не создаёт новую запись.
- Место можно удалить вместе с историей.
- Кнопка «Я здесь» показывает текущее положение на карте.
- Координаты хранятся только на телефоне.

### Обратная связь

- Оценка приложения по пяти звёздам и свободное мнение.
- Отправка идёт из приложения: почтовое приложение не открывается, адрес получателя
  и служебные поля не показываются.
- Копия отзыва может дублироваться в Telegram, если при сборке задан бот.
- Ссылка на последний релиз GitHub — прямо на экране «Отзыв».

### Офлайн и приватность

- Библиотека, тюнер, аккорды, метроном и карта работают без сети.
- Сеть используется для поиска песен и отправки отзыва.
- Аудио с микрофона обрабатывается на устройстве и никуда не отправляется.

## Сборка из исходников

Нужны JDK 17 и Android SDK 36.

```powershell
git clone https://github.com/tcaramovmihail-gif/guitar-tuner.git
cd guitar-tuner

# Windows
.\gradlew.bat :app:assembleDebug

# Linux / macOS
./gradlew :app:assembleDebug
```

Готовый APK: `app/build/outputs/apk/debug/app-debug.apk`.

Необязательное дублирование отзыва в Telegram задаётся при сборке:

```properties
# local.properties
telegram.bot.token=123456:ABC...
telegram.chat.id=123456789
```

Бот должен быть заранее запущен получателем. Без этих полей отзыв уходит только
на почту, а приложение собирается и работает как обычно.

### Тесты и проверки

```powershell
.\gradlew.bat :core:model:test
.\gradlew.bat :core:dsp:test
.\gradlew.bat :core:catalog:test
.\gradlew.bat :core:audio:test
.\gradlew.bat :app:lintDebug
.\gradlew.bat :app:assembleDebug
```

Compose-тесты на устройстве:

```powershell
.\gradlew.bat :app:connectedDebugAndroidTest
```

> Внимание: `connectedDebugAndroidTest` переустанавливает приложение и может стереть
> его данные (импортированные песни). На рабочем телефоне безопаснее `adb install -r`
> и `am instrument` — см. `docs/ENVIRONMENT.md`.

Тюнер проверяется на реальном телефоне: эмулятор не даёт достоверного микрофонного
сигнала. DSP-часть покрыта JVM-тестами на синтетических струнах, расстройке, шуме
и тишине.

## Структура проекта

| Путь | Назначение |
| --- | --- |
| `app/` | Compose UI, навигация, ViewModel, разрешения, экраны тюнера, песен, карты и отзыва |
| `core/model/` | Ноты, строи, транспонирование, аккорды, `StringTracker`, `StringTargeting`, `InTuneHold` (Kotlin JVM) |
| `core/dsp/` | YIN-детектор, сглаживание, обработка сигнала (Kotlin JVM) |
| `core/audio/` | Захват PCM, метроном/барабаны, эталонный тон и аккорды (Android library) |
| `core/catalog/` | HTTP-клиенты и HTML-парсеры AmDm, Akkords.pro и 5Lad (Kotlin JVM + Jsoup) |
| `docs/` | План, архитектура, среда разработки, правила агентов |
| `scripts/` | Скрипты сборки, установки и работы с устройством |
